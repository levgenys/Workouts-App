# Changelog
See the changelogs for each release of Workouts App here

<br>

### `Latest`

## v 1.3
**May, 2025**

New Features & Improvements:
- Added a workout completion screen for a clear summary of your progress. This screen will also display the records you set during the workout.
- Updated the set addition screen — now it opens even faster and is ready for immediate interaction, reducing missed taps and making adding sets quicker and more convenient.


## v 1.2.3
**Apr, 2025**

New Features & Improvements:
- You can now view and edit workout comments in the history section.
- The search field is now immediately visible when adding a new exercise.
- The calendar on the main screen now always shows the correct day, even if you return to the app after a day.


## v 1.2.1
**Mar, 2025**

New Features & Improvements:
- All workouts from the current program are now available in the quick start slider for easier access.
- When renaming an exercise, its max records are now preserved, and the exercise updates correctly in workout programs.

## 1.2
**Feb, 2025**

New Features & Improvements:
- Unit selection – You can now switch between kg and lbs in the settings, and all weights will be converted accordingly, regardless of your region.
- “Start Workout” block – Quickly start your next scheduled workout, repeat the last one, or create a new workout from scratch.
- Swipe actions for exercises – Easily delete or replace an exercise in your current workout by swiping on the exercise cell.
- New onboarding – A step-by-step guide for new users on how to add workouts.
- Simplified exercise editing – The “Done” button now exits edit mode instead of finishing the workout.
- Workout counter added – The history screen now displays the total number of completed workouts.

## 1.1
**Sep, 2024**

Support Section Added: Now you can easily report issues, suggest improvements, copy the app link, and rate it in the App Store directly from the settings.

New Workout Start Button: We've added a button to the navigation bar, allowing you to start a fresh workout without a program in just one tap.

Bug Fixes & Stability Improvements: Various bugs have been squashed, and overall app performance is now smoother.
